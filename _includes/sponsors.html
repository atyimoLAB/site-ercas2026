{% comment %} Versão completa da seção de apoio (página /patrocinio/). Renderiza site.data.sponsors: lista de { category, footer?, items: [ { name, url?, logo?, wide? } ] }. Layout: os 3 grupos ficam lado a lado numa única linha no desktop (>= lg). A largura de cada coluna é fixada por categoria via um `case` em group.category: - Realização → .sponsors-col-realizacao (12,5% em lg+, ver main.scss) - Organização → .sponsors-col-organizacao (62,5% em lg+, ver main.scss) - Patrocínio → col-lg-3 (25%) Abaixo de lg cada grupo ocupa a linha inteira (col-12). O `case` também escolhe o par chip/logo de cada grupo (Realização e Organização têm logos maiores que Patrocínio) e o alinhamento horizontal das chips: em lg+ Organização alinha à esquerda (`justify-content-lg-start`), pois as duas linhas fixas devem começar sob o título; abaixo de lg (colunas empilhadas) volta a centralizar. Realização e Patrocínio ficam sempre centralizados. Em Organização, `wide: true` num item aplica um chip ~2x mais largo (mesma altura) para os lockups horizontais, e `break_before: true` força uma quebra de linha (`.w-100`) antes do item, dividindo a coluna em linhas fixas. Se as categorias do _data/sponsors.yml mudarem, ajuste o `case` abaixo. {% endcomment %}
